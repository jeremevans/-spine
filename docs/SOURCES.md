# Primary sources and scope

Checked 1 November 2026. Descriptions below are summarized; external source
code is not vendored in this repository.

1. [MathWorks interpn](https://www.mathworks.com/help/matlab/ref/interpn.html)
   explicitly specifies not-a-knot conditions for `spline`, small-grid
   fallbacks, grid orientation, and outside-domain handling.
2. [MathWorks: Curve Fitting Toolbox Splines and MATLAB Splines](https://www.mathworks.com/help/curvefit/curve-fitting-toolbox-splines-and-matlab-splines.html),
   “MATLAB Splines” section, identifies `interpn(...,'spline')` as the
   interpolating tensor-product cubic spline. The example here only needs base
   MATLAB; it does not call that toolbox.
3. [SciPy 1.17.0 RegularGridInterpolator](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.interpolate.RegularGridInterpolator.html)
   documents tensor-product splines and direct/iterative coefficient solvers.
   [Versioned implementation](https://github.com/scipy/scipy/blob/v1.17.0/scipy/interpolate/_ndbspline.py):
   `make_ndbspl` states that boundary conditions are not-a-knot in all dimensions
   and calls `_not_a_knot` per axis. The installed source was inspected.
4. [SciPy 1.17.0 CubicSpline](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.interpolate.CubicSpline.html)
   documents the piecewise-polynomial representation and endpoint options.
5. [Octave 8.4.0 multidimensional interpolation](https://docs.octave.org/v8.4.0/Multi_002ddimensional-Interpolation.html)
   and [polynomial interpolation](https://docs.octave.org/v8.4.0/Polynomial-Interpolation.html).
   Implementation locations: `scripts/general/interpn.m`,
   `scripts/general/private/__splinen__.m`, and `scripts/polynomial/spline.m`.
6. [CRAN pracma interp1 reference](https://search.r-project.org/CRAN/refmans/pracma/html/interp1.html)
   describes the MATLAB-compatible `spline` option.
   [Package source mirror](https://github.com/cran/pracma/blob/master/R/interp1.R),
   `.ml.spline`, implements the endpoint equations. `master` is a moving source;
   the actual package version is recorded in each R result.
7. [Cleve Moler, Numerical Computing with MATLAB, Interpolation chapter](https://www.mathworks.com/content/dam/mathworks/mathworks-dot-com/moler/interp.pdf)
   provides background on cubic splines and not-a-knot conditions. The
   second-derivative uniqueness derivation in PROOF.md is written out here so
   the claim does not depend on access to a textbook.
8. [MathWorks setup-matlab action](https://github.com/matlab-actions/setup-matlab)
   and [run-command action](https://github.com/matlab-actions/run-command)
   describe actual MATLAB execution in GitHub Actions. Current documentation
   permits automatic licensing for supported products in public projects;
   private projects need separately configured licensing.

All input surfaces in this focused repository are synthetic and generated by
`scripts/make_fixtures.py`. They are intentionally independent of the earlier
SPX example and its redistribution license. No live market data or proprietary
MATLAB code is included. The prior comparison package is a separate artifact.
